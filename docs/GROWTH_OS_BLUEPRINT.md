# WishNest Growth & Intelligence OS — Locked Blueprint

## Product principle
Campaign Manager is a **control module** inside the Growth & Intelligence OS — not the whole product.

## Final pipeline
```
WishNest Editorial
  → SEO/GEO agent (every approved article/review/intelligence/reimagined)
  → Postiz social distribution
  → Subscribers + traffic
  → Campaigns / Surveys (opted-in: Mautic)
  → Intelligence (segments, clusters, demand signals)
  → Qualified leads / communities
  → ArrowX (commercial only, with consent)
```

## Channel separation
| Path | Tool | Use |
|------|------|-----|
| Magazine continuous | SEO/GEO + Postiz | Every approved editorial piece |
| Cold first-contact | **AgentReach** | Resort-owner sequences (not opted-in) |
| Opted-in nurture | **Mautic** | Email, forms, landing, scoring, campaigns |
| Intelligence | OpenAI + WishNest | Enrichment, campaign orchestrator, GEO |
| Commercial route | WishNest → ArrowX | After qualification + consent |
| Telecaller (later) | LiveKit / Bolna | Qualified queue only |

## GEO-ready
Destinations, entities, schema, internal knowledge graph links.
